# Dotfiles

List of config from my dotfiles.

## Prerequisites
### Kitty

- [Mononoki Nerd Font](https://www.nerdfonts.com/font-downloads)
- Both themes are generated by matugen and gitignored, so pick one once:

  ```sh
  cp ~/.config/kitty/themes/theme.conf.example ~/.config/kitty/themes/theme.conf
  ```

  `theme.conf` includes either `Matugen.conf` (hues keep their names) or
  `MatugenStrict.conf` (purely wallpaper-derived). Without it kitty starts on its
  built-in colors and logs the missing path.

### Zsh

- `fzf` — shell key bindings and completion
- `git` — plugins clone into `~/.local/share/zsh/plugins` on first start;
  `zplugin-update` pulls them
- History and completion-cache directories are not created automatically:

  ```sh
  mkdir -p ~/.local/state/zsh ~/.cache/zsh
  ```

### Neovim

- Neovim >= 0.12 — plugins use the built-in `vim.pack` and install on first launch
- `fd` >= 8.3 and `ripgrep` — Telescope file finding and live grep
- `git` and a C compiler for treesitter parsers

## Install

Symlinked with GNU Stow:

```sh
stow -d ~ -t ~ .dotfiles
```

## Theming

`matugen` regenerates the kitty, btop, neovim, opencode and herdr themes from a
wallpaper. Every generated file is gitignored.

```sh
matugen image ~/wallpaper.png
```
